Sketch Receptor para Arduino / ESP32 
// Sketch Receptor para Transmisión en Vivo OLED Designer
#include <SPI.h>
#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>

// ============================================================
// CONEXIÓN DE PINES I2C:
// - Arduino MEGA 2560:  SDA -> Pin 20 | SCL -> Pin 21  (¡NO usar A4 y A5!)
// - Arduino UNO / Nano: SDA -> Pin A4 | SCL -> Pin A5
// - ESP32:              SDA -> GPIO 21 | SCL -> GPIO 22
// ============================================================

#define ANCHO_PANTALLA 128
#define ALTO_PANTALLA  64
#define OLED_RESET     -1
Adafruit_SSD1306 display(ANCHO_PANTALLA, ALTO_PANTALLA, &Wire, OLED_RESET);

uint8_t buffer[1024];

void setup() {
  Serial.begin(115200);

  // Inicializar pantalla con dirección 0x3C (o 0x3D si es clon)
  if (!display.begin(SSD1306_SWITCHCAPVCC, 0x3C)) { 
    if (!display.begin(SSD1306_SWITCHCAPVCC, 0x3D)) {
      Serial.println(F("Fallo al iniciar SSD1306"));
      for(;;);
    }
  }
  
  display.clearDisplay();
  display.setTextSize(1);
  display.setTextColor(SSD1306_WHITE);
  display.setCursor(0, 10);
  display.println(F("Hola Mundo!"));
  display.setTextSize(2);
  display.setCursor(0, 30);
  display.println(F("Arduino"));
  display.display();
}

void loop() {
  if (Serial.available() >= 4) {
    if (Serial.peek() != 0xAA) {
      Serial.read();
      return;
    }
    Serial.read(); // 0xAA
    if (Serial.read() == 0x55) {
      uint8_t w = Serial.read();
      uint8_t h = Serial.read();
      size_t expected = (w * h) / 8;
      size_t readBytes = Serial.readBytes((char*)buffer, expected);
      if (readBytes == expected) {
        display.clearDisplay();
        display.drawBitmap(0, 0, buffer, w, h, SSD1306_WHITE);
        display.display();
      }
    }
  }
}

📖 Manual de Ayuda y Documentación — OLED-Designer-Suite-Professional

⚡ OLED-Designer-Suite-Professional

Node.js 18+ Electron Desktop Licencia MIT SSD1306 | SH1106 | SSD1309 | SSD1331 | SSD1351

OLED-Designer-Suite-Professional es una aplicación de escritorio integral y de alto rendimiento para diseñar, animar, simular y generar código para pantallas OLED monocromáticas y a color utilizadas en sistemas embebidos (Arduino, ESP32, ESP8266, Raspberry Pi Pico, STM32 y más).

Combina un editor de dibujo en tiempo real, un sistema de animación por fotogramas múltiples (Timeline con Onion Skin), un generador y simulador físico de menús interactivos, un importador de GIFs con Dithering Floyd-Steinberg, un generador de códigos QR 1-bit, un catálogo de widgets paramétricos, modo de pantalla dual (Dual Screen 0x3C/0x3D) y streaming en vivo por USB Serial y WiFi directamente a la pantalla real.

🚀 1. Características Principales

  • Editor 1-bit pixel-perfect: Lienzo con zoom de 1x a 16x, centrado automático, cuadrícula configurable y soporte de resoluciones estándar y personalizadas.
  • Herramientas de dibujo completas: Lápiz, borrador con 5 calibres y borrado rápido con clic derecho, líneas, rectángulos (huecos y rellenos), círculos, relleno por inundación (bucket) y cuentagotas.
  • Capas de texto editables: Arrastre interactivo, alineación (izquierda, centro, derecha), tamaño en tiempo real, edición inline con doble clic y rasterizado al lienzo con "Fijar al Canvas".
  • Exportación PNG 1-bit pura: Codificador nativo W3C PNG monocromo de 1 bit por píxel sin compresión con pérdida.
  • Simulador físico fotorrealista: Réplica de módulo OLED con acabado PCB personalizable (Azul, Negro mate, Púrpura ENIG), pines serigrafiados y 6 colores de display (Blanco, Azul, Amarillo, Verde, Amarillo/Azul split y RGB).
  • Línea de tiempo para animaciones: Control cuadro a cuadro, tira de miniaturas en vivo (Filmstrip), papel cebolla (Onion Skinning), selector de 1 a 24 FPS y bucle de reproducción.
  • Generador de menús con D-Pad físico: Simulador interactivo navegable con flechas del teclado o botones táctiles en pantalla, con soporte de opciones de acción, toggles y rangos numéricos.
  • Conversor GIF y Video a 1-bit: Algoritmo de difusión de error Floyd-Steinberg, binarización adaptativa, auto-contraste e inyección automática en la timeline.
  • Códigos QR 1-bit integrados: Motor Reed-Solomon autónomo y sin dependencias externas para URLs, textos y WiFi.
  • Streaming directo a hardware (USB Serial & WiFi): Transmisión en milisegundos de cada fotograma al microcontrolador real sin tener que compilar ni flashear.
  • Modo Pantalla Dual: Edición y exportación de código sincronizado para 2 pantallas OLED en simultáneo (0x3C y 0x3D).
  • Generadores de código nativos: Código C++, Python y Rust optimizado con diagramas de pines para Arduino Uno, Nano, ESP32, ESP8266 y Raspberry Pi Pico.

🧩 4. Módulos del Sistema

1. Editor Visual y Herramientas

Lápiz (P): Dibujo continuo píxel a píxel con tamaños de 1px a 4px.

Borrador (E): Borrado multicalibre (1px, 2px, 4px, 8px, 12px) con cursor circular rojo de previsualización. También puedes borrar al instante manteniendo pulsado el botón derecho del ratón.

Figuras Geométricas: Líneas rectas (L), Rectángulos huecos y rellenos (R), Círculos y elipses (C).

Bote de Relleno (F): Algoritmo Flood-Fill de llenado de regiones contiguas cerradas.

Cuentagotas (D): Muestreo rápido de color en el punto del cursor.

Capas de Texto Editables (T): Permite escribir textos con fuente de 5×7 px, arrastrarlos libremente por el canvas, cambiar su tamaño y alineación (izquierda, centro, derecha), editarlos con doble clic y fijarlos definitivamente al bitmap con el botón "Fijar al Canvas".

Transformaciones de Lienzo: Invertir píxeles, Voltear H / V, Desplazamiento cardinal (Shift ↑ ↓ ← →) y Limpiar Todo.

Exportación PNG 1-Bit: Botón "PNG 1-bit" en la barra superior que genera una imagen PNG monocromática indexada (1 bit/pixel) con paleta binaria limpia para documentación, hojas de datos o impresión.

2. Simulador de Hardware Físico

Modal interactivo accesible desde el botón Simulador de la barra superior.

Acabados de PCB: Azul clásico, Negro mate profesional y Púrpura ENIG con contactos dorados.

Pines serigrafiados: Identificación de terminales físicos: GND, VCC, SCL, SDA.

Paletas de Color OLED: Blanco puro, Azul neón, Amarillo ámbar, Verde matriz, Amarillo/Azul dividido (Dual Split 16/48px) y Modo RGB.

Acciones: Botones para copiar la captura del módulo al portapapeles o descargar la foto HD en PNG.

3. Biblioteca de Widgets e Iconos 1-Bit (widgets.js)

Accesible mediante el botón 🧩 Widgets o pulsando la tecla W.

30+ Iconos Vectorizados para 1-bit: Baterías (100%, 75%, 50%, 25%, Cargando ⚡), WiFi (3 niveles), Bluetooth, USB, Termómetro, Gota de humedad, Sol, Rayo, Corazón, Velocímetro, Engranaje, Candado, Campana, Alerta, Checkmark, Cruz, Reloj y Flechas de control.

Widgets Paramétricos Pro: Barra de progreso deslizable (continua o segmentada VU meter), Tacómetro analógico (Gauge Dial con aguja en vivo), Barra de Estado superior (Header Bar de 128px con WiFi/Batería), Mini Gráfica Sparkline y Tarjeta Sensor Metric Card.

4. Sistema de Animaciones y Línea de Tiempo

Accesible mediante el botón 🎬 Animación o el atajo Shift + A.

Barra de Línea de Tiempo (Timeline): Se despliega en la parte inferior del espacio de trabajo con Tira de Miniaturas (Filmstrip) interactiva.

Gestión Cuadro a Cuadro: + Frame (crear), ⧉ Duplicar (clonar) y 🗑 Borrar (eliminar).

🧅 Papel Cebolla (Onion Skinning): Muestra el fotograma anterior con un resplandor translúcido naranja (rgba(255, 128, 0, 0.4)) por debajo del dibujo actual para guiar la animación fluida.

Controles de Reproducción: Botones ⏮ Primero, ◀ Anterior, ▶ / ⏸ Play / Pausa (atajo Espacio), Siguiente ▶, ⏭ Último, selector de velocidad de 1 a 24 FPS y bucle continuo (Loop).

5. Generador y Simulador de Menús OLED (menuDesigner.js)

Accesible mediante el botón 📑 Menús o la tecla M.

4 Estilos Visuales: Barra Invertida (highlight blanco con texto negro), Flecha Cursor (>), Punto Bullet (●) y Caja con Borde.

Tipos de Elementos: Acciones, Toggles [ON]/[OFF] y Rangos/Valores numéricos.

Simulador Físico con D-Pad: Navegable con botones virtuales o teclas ↑/↓ para desplazarse, Enter para accionar y ←/→ para modificar valores.

Acciones: Botón "Estampar en Canvas" y generador de código C++ Arduino y MicroPython listo con INPUT_PULLUP.

6. Importador de GIFs y Videos con Dithering (gifDecoder.js)

Accesible mediante el botón GIF/Video.

Acepta archivos .gif, videos .mp4, .webm e imágenes estándar.

Dithering Floyd-Steinberg: Difusión de error que recrea gradientes analógicos suaves en 1 bit monocromo puro.

Controles: Slider de umbral de binarización (1 a 254), auto-contraste de histograma e inversión de colores.

Aplicar a Timeline: Transfiere todos los fotogramas procesados a la Línea de Tiempo en un clic.

7. Generador de Códigos QR 1-Bit (qrGenerator.js)

Accesible mediante el botón QR.

Motor Reed-Solomon Integrado: Genera códigos QR Version 1 (21×21) a Version 3 (29×29) de forma 100% offline para URLs, textos y redes WiFi.

Escalas: 1x, 2x y 3x con zona silenciosa blanca para lectura óptica perfecta en smartphones.

Acciones: Estampar en canvas o agregar como nuevo fotograma.

8. Biblioteca de Plantillas y Diseños Animados (animTemplates.js)

Accesible mediante el botón Plantillas.

Colección de más de 18 animaciones listas agrupadas en categorías: 🎮 Juegos (Pac-Man Arcade, Latido de Corazón, Pelota Rebotando), ✨ Efectos FX (Warp Speed 3D, Lluvia Matrix, Ripple, Lluvia, Seno), ⌚ Relojes (Digital 7-Seg, Analógico), 🔋 Hardware (Batería, Señal Móvil, ECG, Radar, Spinner) y 🤖 Ojos/Caras (Smiley, Ojos Cozmo).

Buscador interactivo en vivo, previsualización animada a FPS reales en cada tarjeta y carga instantánea a la Línea de Tiempo.

9. Modo Doble Pantalla OLED (Dual Screen)

Accesible mediante el botón Dual OLED.

Permite alternar y editar independientemente la Pantalla A (0x3C) y la Pantalla B (0x3D).

Genera el sketch Arduino C++ unificado con displayA y displayB inicializados y sincronizados en el loop().

10. Transmisión en Vivo y Subida Directa a Placa (1-Click Upload)

Accesible mediante el botón Hardware (con indicador LED de conexión).

Detección de Placas e Identificación de Pines I2C: Reconoce automáticamente Arduino Mega 2560 (pines 20/21), Uno/Nano (A4/A5), Leonardo (2/3), ESP32 (21/22), ESP8266 (D2/D1) y Raspberry Pi Pico RP2040 (GP4/GP5) con tarjetas visuales del conexionado.

Subida Directa (⚡ Subir a la Placa): Compila y flashea el sketch receptor automáticamente a la placa con un clic gracias a arduino-cli sin necesidad de herramientas externas.

Conexión Serie Nativa Node.js: Transmisión ultra rápida y estable sin bloqueos a 115200 baudios.

WiFi Streaming: Envío inalámbrico a la dirección IP de un ESP8266 o ESP32.

Sketch Receptor con Autodiagnóstico: Detección automática de direcciones I2C 0x3C / 0x3D y alerta con LED 13.

💻 5. Generación de Código Multi-Plataforma

El generador src/codeGen.js produce código limpio y listo para compilar en:

  • Arduino + Adafruit GFX: Inicialización I2C (400kHz) y SPI con pinouts, PROGMEM bitmaps, loops de animación y soporte de doble pantalla.
  • U8g2: Constructores para hardware/software I2C y SPI con u8g2.drawXBMP().
  • MicroPython: Control para Raspberry Pi Pico y ESP32 con ssd1306.py y framebuf.MONO_HLSB.
  • CircuitPython: Módulos adafruit_ssd1306 y adafruit_framebuf.
  • C Array Puro (.h): Cabeceras de bytes exportables para cualquier microcontrolador.
  • Rust: Compatible con la librería embedded-graphics y ImageRaw<BinaryColor>.
  • JavaScript / Canvas: Emulador web interactivo.

🤖 6. Inteligencia Artificial Integrada

1. Motor Local Heurístico (100% Offline y Gratuito):

  • Analiza densidad de píxeles, centro de masa y patrones visuales.
  • Detecta regiones de texto y marcos para sugerir llamadas vectoriales (display.println(), display.drawRect()) que ahorran memoria RAM.
  • Inserta comentarios didácticos en español y diagramas de pines físicos según la placa seleccionada.

2. Motor Cloud OpenAI (Opcional):

Compatible con gpt-4o-mini definiendo la variable de entorno OPENAI_API_KEY.

🗄️ 9. Base de Datos y Persistencia Local

1. Modo Local Offline (Por defecto):

Si no tienes PostgreSQL instalado o configurado, la aplicación detecta automáticamente la ausencia del servicio y activa el Modo Offline. Los proyectos, fotogramas y configuraciones se guardan localmente en el almacenamiento seguro de la aplicación (localStorage de Electron y archivos .oled), permitiendo trabajar sin conexión a internet ni bases de datos activas.

2. Modo PostgreSQL (Opcional):

Para activar la base de datos relacional completa, ejecuta PowerShell como Administrador:

powershell -ExecutionPolicy Bypass -File scripts\setup_postgres.ps1

Almacena historial de versiones (hasta 20 por proyecto), plantillas de drivers personalizadas y metadatos relacionales.
